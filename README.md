# zelefy

## Структура

```
zelefy/
├── apps/
│   # --- КЛИЕНТЫ (pnpm + React) ---
│   ├── web/                    # Сайт (Vite / Next.js)
│   ├── desktop/                # Tauri приложение (React + Rust-ядро)
│   # --- БЭКЕНД СЕРВИСЫ ---
│   ├── api-gateway/            # API Gateway на RUST (Axum) -> Входная точка
│   ├── service-catalog/        # FastAPI (uv) -> Треки, плейлисты, поиск
│   ├── service-users/          # FastAPI (uv) -> Авторизация, профили
│   └── service-audio/          # RUST (Cargo) -> Обработка, сжатие, стриминг
│
├── packages/                   # ОБЩИЕ ПАКЕТЫ И КОНТРАКТЫ
│   ├── ts-shared/              # Общие TypeScript типы и API-клиент (pnpm)
│   └── py-shared/              # Общие Pydantic-схемы данных для FastAPI (uv)
│
├── infra/                      # ИНФРАСТРУКТУРА ЛОКАЛЬНОГО ОКУЖЕНИЯ
│   ├── docker-compose.yml      # Запуск Postgres, Redis и всех бэк-сервисов
│   └── .env.example            # Шаблон переменных окружения
│
├── pnpm-workspace.yaml         # Конфигурация воркспейса для фронтенда
├── pyproject.toml              # Конфигурация воркспейса uv (Python)
├── Cargo.toml                  # Конфигурация воркспейса Cargo (Rust)
└── turbo.json                  # Оркестратор сборки (Turborepo)
```

## Как это работает вместе (Потоки данных)

   1. Входной запрос: Сайт (web) или приложение (desktop) отправляют запрос на единый порт API Gateway (Rust, порт 8000).
   2. Защита и Авторизация: Шлюз проверяет лимиты (спам), валидирует JWT-токен и «пробрасывает» запрос дальше во внутреннюю сеть Docker до нужного микросервиса.
   3. Хранение данных:
   * PostgreSQL — основная база (пользователи, метаданные треков, плейлисты).
      * Redis — кэширование частых запросов, сессий и хранение лимитов для шлюза (Rate Limiting).
   4. Сквозная синхронизация: Изменения в packages/py-shared мгновенно видны во всех Python-сервисах. Изменения типов в packages/ts-shared сразу подхватываются и сайтом, и Tauri.
